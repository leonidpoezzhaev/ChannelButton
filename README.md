# ChannelButton

**Бот для публикации постов с интерактивными кнопками в Telegram-каналах**

## 📖 О проекте

**ChannelButton** — это Telegram-бот, который позволяет публиковать посты с кнопками в один или несколько каналов одновременно. Проект создан с целью практики и экспериментов с библиотеками `pyTelegramBotAPI` и `SQLite3`.

### Основные возможности

- ✅ **Публикация постов с кнопками** — создавайте посты с интерактивными inline-кнопками для ваших каналов.
- 📢 **Мультиканальная публикация** — отправляйте один пост сразу в несколько каналов (хоть во все).
- 🔒 **Проверка подписки** — бот проверяет, подписан ли пользователь на обязательный канал, перед тем как дать доступ к функциям.
- ⭐ **Premium-подписка** — частичная реализация платной подписки для расширенного доступа.
- 🗄️ **Хранение данных** — все данные пользователей и настройки хранятся в базе данных SQLite.

## 🚀 Быстрый старт

### Требования

- Python 3.7 или выше
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))
- ID канала (для проверки подписки)

### Установка

1. **Клонируйте репозиторий**

```bash
git clone https://github.com/leonidpoezzhaev/ChannelButton.git
cd ChannelButton
```

2. **Установите зависимости**

```bash
pip install -r requirements.txt
```

3. **Настройте бота**

Откройте файл `chanel_button.py` и укажите ваш токен и ID канала:

```python
bot = telebot.TeleBot('YOUR_BOT_TOKEN_HERE')
chanel = '-1003480826321'  # ID вашего канала
```

4. **Запустите бота**

```bash
python chanel_button.py
```

## 🎮 Использование

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начало работы с ботом, проверка подписки |
| `/give_premium` | Выдача Premium-статуса пользователю (только для администратора) |

### Основной сценарий работы

1. Пользователь отправляет команду `/start`.
2. Бот проверяет подписку на указанный канал.
3. После подтверждения подписки открывается главное меню:

   - **Новый пост** — создание поста для публикации
   - **❓Инструкция** — помощь по использованию бота
   - **⚙️Настроить каналы** — управление списком каналов для публикации
   - **⭐️Premium** — информация о премиум-доступе

4. Администратор может выдавать Premium-статус через команду `/give_premium @username`.

## 🛠️ Технологии
